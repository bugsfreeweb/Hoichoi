# Bundled poster fonts

All faces are Unicode Bengali and are distributed under the SIL Open Font
License 1.1. They are bundled (not fetched at render time) so a headless render
is deterministic and offline-safe.

| File | Family | Source |
| --- | --- | --- |
| `HindSiliguri-Regular.ttf` | Hind Siliguri 400 | https://github.com/google/fonts/tree/main/ofl/hindsiliguri |
| `HindSiliguri-Medium.ttf` | Hind Siliguri 500 | same |
| `HindSiliguri-SemiBold.ttf` | Hind Siliguri 600 | same |
| `HindSiliguri-Bold.ttf` | Hind Siliguri 700 | same |
| `Galada-Regular.ttf` | Galada 400 | https://github.com/google/fonts/tree/main/ofl/galada |
| `NotoSansBengali-Regular.ttf` | Noto Sans Bengali 400 | https://github.com/google/fonts/tree/main/ofl/notosansbengali |
| `NotoSansBengali-Bold.ttf` | Noto Sans Bengali 700 | same |
| `NotoSerifBengali-SemiBold.ttf` | Noto Serif Bengali 600 | https://github.com/google/fonts/tree/main/ofl/notoserifbengali |
| `NotoSerifBengali-Bold.ttf` | Noto Serif Bengali 700 | same |

The license text is in `OFL.txt` in this directory.
