# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and leaders pledge to make participation in our
community a harassment-free experience for everyone.

The full text of the Contributor Covenant is to be added by the maintainers
before the repository is opened to public contribution.

## Enforcement

If you experience or witness unacceptable behavior, contact
<contact@hoichoi.local>. Members asked to stop are expected to comply.
